# Developer Portfolio

Foundation for a personal developer portfolio built with Next.js, TypeScript, and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in a browser.

## Available scripts

- `npm run dev` starts the development server.
- `npm run build` creates a production build.
- `npm run start` serves the production build.
- `npm run lint` runs ESLint.
- `npm run format` formats supported files with Prettier.
- `npm run format:check` checks formatting without changing files.

## Structure

- `src/app` contains App Router routes and global styles.
- `src/components/layout` contains site-wide layout components.
- `src/components/ui` contains reusable UI primitives.
- `src/lib` contains typed application data and domain helpers.
- `src/types` contains shared TypeScript types.
